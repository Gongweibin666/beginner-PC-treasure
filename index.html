电脑小白的宝藏

你不是学不会电脑。
你只是，没遇到一个愿意慢慢讲的人。

参考《你缺计课》基础篇 精简改写 · 非官方 免费阅读

向下

有些话，
从来没有被认真讲过。

比如：电脑不是什么高深的东西。它只是一台会发热的机器，被人类教会了听指令。

比如：你不会用它，不是因为你笨。只是那些被当作“常识”的东西，从来没人慢慢说给你听。

比如：那些看起来“什么都会”的人，也曾在某个下午，对着一个弹窗手足无措，最后假装有事走开。

这本书想做一件很小的事——把《你缺计课》基础篇里最要紧的部分，重新讲一遍。不讲原理，不讲历史，只讲你明天就会用到的：怎么认它、怎么整理它、怎么装软件、怎么保护自己、卡住了怎么办。

它很短。短到你可以在等一份外卖的时间里读完。但它希望，读完以后的你，能在这台机器面前，坐得直一点。

“它不是大部头而刻板的教材。它希望和你成为朋友，与你一同踏上一场轻松愉快的旅程。”

——《你缺计课》序

为什么叫“宝藏”？
因为真正的宝藏，从来不是某个神秘软件，也不是一串快捷键。是那种“这件事我可以自己搞定”的底气。它不响，但很沉。

01

认识它

电脑不神秘，它只是不说话。

我们对电脑的恐惧，多半来自它的沉默。它不会告诉你为什么卡，也不会告诉你文件去了哪里。可一旦你知道了它内部那几样东西的名字和分工，它就从一个黑箱，变成一张你能看懂的桌子。

处理器

CPU · 那个负责想事情的人

你点一下，它算一下。它越快，你等得越少。i5、i7 不必背，够用就是好。

内存

RAM · 桌面上摊开的地方

越大，能同时摊开的东西越多。一断电就清空。电脑卡，常常是桌子太小。

硬盘

Disk · 抽屉和书柜

东西存在这里，关了机也还在。装不下的时候，删的是柜子里的东西，不是桌子。

显卡

GPU · 专门画画的助手

游戏、剪辑、设计时它最忙；日常办公，它通常闲着。别为它多花冤枉钱。

系统

Windows · 这间屋子的规矩

Windows 是屋子本身，软件是住进来的客人。屋子乱了可以收拾，不必推倒重来。

接口

USB / HDMI · 让它和世界握手

插对了才有反应。插不进去的时候，别硬怼，翻个面，或者换一个口。

记住一个最实用的判据：电脑卡，看内存和磁盘；存不下，看硬盘。按 Ctrl + Shift + Esc 打开任务管理器，那个跳动的百分比，就是它此刻的呼吸。

记住这一句

内存是桌子，硬盘是柜子。
桌子小会乱，柜子满会挤。

02

文件

你丢的不是文件，
是没给它一个家。

每个人都曾有一个“找不到的文件”。它叫“新建文本文档 (3).txt”，躺在下载文件夹的第三页；或者被你改名成“最终版真的最终.docx”，然后永远留在了桌面。文件不会自己走丢，它只是从来没有被安排好住处。

  • 名字由两半组成：主名 + 扩展名。扩展名不是装饰，它决定了“由谁来打开它”：.docx 交给 Word，.jpg 是图片，.mp4 是视频，.zip／.7z 是压缩包，.exe 是程序本身。改扩展名，等于换一把钥匙去开另一把锁。
  • 请一定让扩展名显示出来。资源管理器 →【查看】→ 勾选【文件扩展名】。否则 高数速成秘籍.docx.exe 会伪装成 Word 文档，双击就运行了一个程序——很多病毒，就是这样大摇大摆进门的。
  • 路径是地址。C:\用户\你的名字\桌面：分区是楼，文件夹是房间，文件是住在里面的人。
  • C 盘是系统的家。别把大文件堆在 C 盘根目录；“桌面”“文档”“图片”这些常用文件夹可以整体搬到别的盘（右键 →【属性】→【位置】）。
  • 整理的方法很朴素：按用途建文件夹（学习／工作／素材／临时），文件名带上日期（2025-03-14 论文初稿.docx），每月清一次“下载”。不必精致，只要一致。
  • 解压时选“解压到 <文件名>\”。选“解压到当前文件夹”，会在你的桌面上炸开一地碎片，而你会以为是自己弄乱了。
扩展名它是什么由谁打开
.docx / .xlsx / .pptx文档 / 表格 / 幻灯片Word、Excel、PowerPoint 或 WPS
.jpg / .png / .gif图片照片查看器、浏览器
.mp4 / .mp3视频 / 音频播放器（装个 VLC 基本通吃）
.zip / .7z / .rar压缩包压缩工具（7-Zip、Bandizip 等）
.exe程序本身双击即运行，不需要别人来开
.pdf版式固定的文档浏览器、SumatraPDF、Edge
记住这一句

给文件一个家，
它就不会在你需要的时候失踪。

03

软件

每一次“下载”，
都是一次判断。

下载软件，是电脑小白最容易受伤的地方。网页上最大的那个绿色按钮，往往不是你要的东西；写着“高速下载”的，通常是一个下载器；而真正的安装包，常常安静地躺在页面最下面，写着小小的“普通下载”。

  • 先官网，再商店。官方网站永远最干净；其次是微软应用商店；最后才轮到第三方站点，并且只点“普通下载”，绕开所有闪动的按钮。
  • 看体积。正经软件动辄几十上百 MB，只有几百 KB 的“安装包”，多半是个下载器，会带着一堆“全家桶”回来。
  • 安装时慢一点。每一步都看一眼，把勾选着的“附加软件”“推荐安装”全部取消。你点“下一步”的速度，决定了电脑将来的干净程度。
  • 把安装路径里的 C 改成 D。C:\Program Files\QQ 改成 D:\Program Files\QQ，目录结构就整齐了。别把软件装到桌面——桌面是给人看的，不是给程序住的。
  • 收费软件别用“破解版”。你省下的那点钱，可能会用隐私、稳定，甚至一次重装系统来还。
  • 卸载要走正门。设置 →【应用】→【安装的应用】→【卸载】。删桌面图标、删程序文件夹，都只是“假装它走了”——它还在，只是你看不见。

一组可以放心用的免费软件：7-Zip（压缩）、VLC（播放）、SumatraPDF（看 PDF）、Firefox 或 Chrome（浏览器）、Everything（秒速找文件）。它们不弹窗、不捆绑，也不问你“要不要开通会员”。

记住这一句

你的谨慎，
比任何杀毒软件都管用。

04

安全

把门关好，
再安心睡觉。

电脑也会累，也会怕。它怕看不懂的程序向它要权限，怕来路不明的 U 盘，怕你随手点开的那条“恭喜中奖”。

  • 那个弹窗是门卫，不是敌人。“是否允许此应用对你的设备进行更改？”——看清程序名字。不认识，就点“否”。这是你电脑上最有用的一个按钮。
  • Windows 安全中心已经够用。不必再装三四个“管家”，它们会互相打架，还占着你的桌子。杀毒软件，一个就够。
  • 更新别永远拖着。它补的是别人已经发现的洞。“重启”也不等于“关机再开机”——要更新，就老老实实点【重启】。
  • 备份，是给自己留的退路。重要的东西至少放两个地方：电脑一份，移动硬盘或网盘一份。3-2-1 法则：三份副本，两种介质，一份在别处。
  • 防诈骗只有三条：不点陌生链接，不把验证码告诉任何人，不给陌生人转账。真正的客服，永远不会问你要密码。
  • 离开座位时按 Win + L。锁屏三秒钟，胜过事后解释三天。
记住这一句

安全不是疑神疑鬼，
是把门关好，再安心睡觉。

05

求助

会提问的人，
永远有人愿意帮。

卡住的时候，人最容易怀疑自己。其实大部分问题，都不是“你不行”，而是“信息不够”。

  • 先重启。这不是敷衍，是真的能解决一大半问题。电脑和人一样，也需要睡一觉。
  • 搜索的关键词，是“软件名 + 你做了什么 + 看到什么”。例如：微信 无法登录 错误码 1001。用引号锁住专有名词，用 site: 限定网站，优先看近两年的答案。
  • 中文搜不到，就换英文再搜一次。很多问题，世界上早就有人问过、也早就有人答过。
  • 提问时，把四件事说清楚：我想做什么、我做了什么、实际发生了什么、报错原文是什么。帮你的人最怕的，不是你不会，而是你说“就是不行”。
  • AI 很好用，但它会一本正经地编。涉及数据、金钱、系统设置，务必再核对一遍。把它当助手，别当神仙。
  • 也别怕问“蠢问题”。所有高手，都是从问蠢问题开始的；所有善意，也都是从被耐心回答开始的。
记住这一句

先重启，再搜索，
最后才动手改设置。

06

让手，
跟上脑子。

试一试

三道小题

不考记忆，只考你有没有真的看懂。答错了也没关系——这一次，你至少知道了门在哪儿。

Q1

一个文件叫「高数速成秘籍.docx.exe」，它最可能是什么？

电脑只认最后一个扩展名。.exe 说明它是个程序；前面那个 .docx 只是名字的一部分，是它穿的衣服。这也是为什么——请让扩展名显示出来。

Q2

电脑很卡，最该先打开哪里看一眼？

按 Ctrl+Shift+Esc 打开任务管理器。看看是谁在占着你的桌子——通常是一个你不认识的程序，或者二十个没关的标签页。

Q3

下载页面上那个最大、最亮、写着「高速下载」的按钮，通常意味着什么？

真正的东西，常常是页面最下面那个不起眼的「普通下载」。慢一点，看清楚再点——这份谨慎，会替你省下很多个重装系统的夜晚。

一页纸的小抄

记不住全文，就先记住这十条。它们能挡住生活里绝大多数的手足无措。

  1. 卡了，先按 Ctrl+Shift+Esc，看是谁在占资源。
  2. 看不到扩展名，就去【查看】里打开它——这是防骗的第一步。
  3. 装软件三步：官网 →「普通下载」→ 取消所有捆绑勾选。
  4. 安装路径把 C 改成 D，别装到桌面，也别装进中文名很长的文件夹。
  5. 卸载走正门：设置 →【应用】→【卸载】，不要直接删文件夹。
  6. 解压选「解压到同名文件夹」，别让文件在桌面炸开。
  7. 重要文件放两处：电脑一份，移动硬盘或网盘一份。
  8. UAC 弹窗看不懂，就点「否」；不确定，就再等一分钟。
  9. 求助时给出：软件名、你做了什么、报错原文。别只说“就是不行”。
  10. 离开电脑按 Win+L；改设置之前，先重启、先搜索。

写给未来的你

有一天你会发现，电脑不再是一个需要鼓起勇气才敢碰的东西。

它变回它本来的样子：一张桌子，一支笔，一扇窗。

你在这里写下的每一份作业、存下的每一张照片、发出的每一封信，都是你认真生活过的证据。

这份“宝藏”里其实没有秘籍。只有一些被认真讲过、也被你认真听过的常识。它们不会让你变成高手，但会让你不再害怕。

愿你从此不怕黑屏，也不怕提问。
愿你被这个世界温柔以待，也有能力，温柔地对待下一台电脑。
