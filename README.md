# 电脑小白的宝藏

一份给普通人的电脑常识精简读本 —— 参考《你缺计课》（《你缺失的那门计算机课》）第一部分「基础篇」重写而成。

## 怎么打开

双击 `index.html` 即可，不需要联网、不需要安装任何东西。单个文件，拷到 U 盘里也能看。

- 右上角的月亮 / 太阳按钮，可以切换「纸页」与「夜读」两种主题；
- 顶部导航会跟着你的阅读进度变化，点击可以跳到对应章节；
- 读完六章后有三道小题，答错了会给一句解释，不会扣分；
- 浏览器打印时可以删掉导航与自测，只留正文。

## 怎么分享

1. **发压缩包**：把整个文件夹压缩后发送，对方解压、双击 index.html。
2. **发 PDF**：手机、平板都能直接看，不会出现「打不开网页」的问题。
3. **同一 WiFi 下临时给对方看**：在电脑上开一个本地服务器，用手机浏览器访问电脑的局域网地址。
4. **做成链接**：把 index.html 传到任意静态托管（GitHub Pages、Cloudflare Pages、Gitee Pages 等），得到网址后分享即可。
